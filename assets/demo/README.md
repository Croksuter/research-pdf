# Demo paper

The welcome page opens a short "paper" about ResearchPDF itself, so every
feature can be tried on it (two figures and a table for figure capture).
Sources here; the compiled PDFs are published on the site at
`docs/demo/researchpdf-demo-{en,ko}.pdf`
(https://research-pdf.croksuter.com/demo/…).

```bash
tectonic researchpdf-demo-en.tex
tectonic researchpdf-demo-ko.tex   # XeTeX + kotex, Noto CJK KR fonts
cp researchpdf-demo-*.pdf ../../docs/demo/
```
