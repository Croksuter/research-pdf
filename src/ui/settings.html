PDF 열기

웹 PDF도 ResearchPDF로 열기

주소로 연 PDF(https://…)를 내장 뷰어로 엽니다. 켜면 사이트 접근 권한을 요청하며, PDF를 가져와 뷰어로 돌리는 데만 씁니다.

컴퓨터의 PDF를 ResearchPDF로 열기

file:// 로 연 PDF를 Chrome 기본 뷰어 대신 내장 뷰어로 엽니다. Chrome의 확장 프로그램 세부정보에서 "파일 URL에 대한 액세스 허용"이 켜져 있어야 합니다.

닫힌 PDF 탭 복구

확장 프로그램이 업데이트되면 Chrome이 PDF 탭을 닫습니다. 보통 자동으로 다시 열리며, 안 됐을 때 씁니다.

논문 정보

논문 정보 표시

논문(DOI·arXiv·제목)을 알아보면 게재처, 인용 수와 추이, 참고문헌, 링크를 보여줍니다. 식별자만 OpenAlex·Crossref·arXiv·Semantic Scholar에 보냅니다.

키 없이 쓰면 같은 네트워크(IP)의 모든 사용자가 하루 한도를 나눠 씁니다. 무료 키는 openalex.org에 가입하면 받습니다.

키가 없으면 공용 익명 한도를 써서 붐빌 때 인용 수가 빠질 수 있습니다. 키는 semanticscholar.org에서 신청합니다.
