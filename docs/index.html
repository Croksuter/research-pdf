ResearchPDF

논문 PDF를 위한 Chrome 뷰어. 그림과 읽던 위치가 내 Google Drive를 통해 모든 Chrome 프로필과 기기를 따라다닙니다.

기능

  • 로컬 파일과 웹 PDF를 내장 PDF.js 뷰어로 엽니다. 펜, 하이라이트, 텍스트, 스탬프 주석을 지원합니다.
  • 같은 논문을 어디서 열든 그림과 읽던 페이지·확대 상태가 그대로 돌아옵니다. 파일 내용으로 문서를 식별하므로 파일 이름이나 경로가 달라도 됩니다.
  • DOI·arXiv를 인식하면 게재처, 인용 수 추이, 참고문헌, 외부 링크를 보여줍니다.
  • Google 계정을 연결하면 Drive의 앱 전용 숨김 폴더로 그림과 읽던 위치를 동기화합니다. PDF 파일 자체는 업로드하지 않습니다.
  • 확장 프로그램 업데이트로 닫힌 뷰어 탭을 자동으로 복구합니다.

개인정보

PDF는 브라우저 안에서만 읽고 어디에도 보내지 않습니다. 자세한 내용은 개인정보처리방침을 보세요.
